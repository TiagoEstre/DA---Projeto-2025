Trata-se de uma aplicação para gerir em tempo real as tarefas dadas aos programadores. O estado atual das tarefas, o tempo que levaram a efetuá-las, assim como o tempo previsto para concluir as mesmas. Prevendo assim se o prazo de entrega é dentro do estabelecido ou não.

INSTALAÇÃO:

Computador com o Microsoft Visual Studio 2022 para abrir o programa.

Para Usar a base de dados deverá ser efetuada a migração da mesma começando por fazer os seguintes comandos:
Enable-Migrations

Add-Migration <iTasksContext>

Update-Database

UTILIZAR:

Faça START

Irá aparecer o formulário de registo para o utilizador (Administrador) preencher os campos. E a seguir entra no login.

Seguidamente poderá não só registar tarefas como utilizadores do programa quer eles sejam gestores ou programadores.

Os gestores que tenham assinalado gereutilizadores poderão também registar tarefas e utilizadores.

Os programadores só tem acesso as tarefas mas não podem criar tarefas.
